
Les tutorials ont pour but d'apprendre au joueur les différentes méchaniques de gameplay. Pour ne pas tomber dans le piège de l'**ENFER TUTORIALISTIQUE**, on fera attention à garder des tutoriels :

- **immersifs & intuitifs**
	- avec le moins de texte possible
	- centrés sur l'action
	- avec des transitions fluides
- **courts**
	- prennent le moins de temps possible
	- faut qu'ils soient les plus concis possible

On peut séparer les tutorials nécessaires en 2 sous catégories :


# 1. Tutoriel de capacité

- arrive quand on récupère des items importants QUE pour la première fois :
	- **shoes**
	- **katana**
	- **laptop**

- on doit faire un appui long sur **A** pour récupérer l'item
- pendant qu'on grab long y'a un effet qui se joue :
	- sound design riser qui monte
	- léger zoom visuel
	- cet effet s'arrête d'un coup si on interrompt le grab
	- le temps ralentit progressivement

- une fois l'item grabbed, une animation se lance et le tutoriel s'affiche :
	- le temps est arrêté
	- animation ui type lancement de combat de maitre d'arene dans pokemon (avec un bandeau horizontal qui se déroule des deux cotés vers le centre, puis l'item apparait avec écrit "katana débloqué")
	- puis y'a le texte du tuto qui s'affiche au milieu :
		- press "Y" to attack
	- une fois qu'on a appuyé sur Y alors le tuto s'arrête d'un coup, le temps reprend et on attaque en même temps
